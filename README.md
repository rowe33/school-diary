# 📘 Шкільний Щоденник

Веб-застосунок шкільного розкладу та щоденника домашніх завдань з інтерфейсом у стилі macOS/iOS. Повністю українською мовою.

## ✨ Можливості

### 🗓️ Розклад по тижнях і чвертях
- Перегляд розкладу уроків потижнево, з навігацією "Попередній / Наступний тиждень", швидким переходом на будь-яку дату та вибором чверті напряму зі списку.
- Розклад розбито на **чверті** — для кожної можна задати свій набір уроків. Якщо розклад на чверть ще не готовий, замість таблиці показується акуратна заглушка "Розклад ще не завантажено".
- Навігація жорстко обмежена рамками навчального року — прогорнути стрічку до 1 вересня чи після завершення літніх канікул неможливо.

### 🎉 Канікули та свята
- Дні канікул (осінні, зимові, весняні, літні) автоматично показуються окремим екраном із назвою періоду замість таблиці уроків.
- Державні та памʼятні дати (Різдво, День Вишиванки, 8 Березня тощо) підсвічують всю картку відповідного дня особливим кольором — їх легко помітити з першого погляду.

### 📝 Домашні завдання
- Кожен урок відкривається у детальній картці: текст завдання, тип роботи (самостійна / практична / контрольна) та галерея фото.
- Пряме у розкладі, поруч із предметом, видно короткий превʼю тексту завдання — не потрібно відкривати картку, щоб зрозуміти, що щось задано.
- До завдання можна прикріпити кілька фотографій (наприклад, фото сторінки підручника) — вони відкриваються у повноекранному перегляді з гортанням.
- Біля кожного завдання видно, хто його додав чи востаннє редагував.

### 🙋 Просте "імʼя" без реєстрації
- При першому відкритті застосунок ввічливо запитує імʼя (без пароля чи пошти) — воно потрібно лише для позначки "Додав(ла): …" біля завдань.
- Імʼя завжди можна змінити одним дотиком у хедері.

### 🤖 ШІ-асистент
- Вбудований чат-помічник, який знає поточний розклад і список ДЗ на тиждень.
- Допомагає спланувати час і нагадує про контрольні — але **ніколи не розвʼязує завдання за учня**, лише підказує, з чого почати.
- На запити не по темі чемно відповідає, що може допомагати лише з розкладом і домашніми завданнями.
- Має вбудований ліміт запитів на годину, щоб не зловживати API.

### 🎨 Інтерфейс
- Дизайн у стилі macOS/iOS: скляні панелі з розмиттям фону, м'які тіні, акуратна типографіка.
- Світла та темна тема з перемиканням одним дотиком і збереженням вибору.
- Адаптивний вигляд — однаково зручно користуватись і з телефону, і з десктопа.

## 🧱 Стек технологій

Vue 3 (Composition API) + Vite · Tailwind CSS · Supabase (PostgreSQL) · ImgBB API (зберігання фото) · Gemini API (ШІ-асистент) · деплой на Netlify.

---

## ⚙️ Налаштування під себе

Уся ключова інформація — розклад уроків, чверті, канікули та свята — винесена у прості конфігураційні файли (`src/config/`), тож редагувати їх під власний навчальний заклад можна без знання Vue чи JavaScript на глибокому рівні.
